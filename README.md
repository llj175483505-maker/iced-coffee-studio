# 冰咖啡工作室 · 交互软件作品集

**网站：** https://llj175483505-maker.github.io/iced-coffee-studio/

**源码：** https://github.com/llj175483505-maker/iced-coffee-studio

深色与冰蓝色的静态作品集，展示五个软件项目：

- 展厅中央控制系统：可视化编辑、指令编排、PC 与安卓平板运行。
- 多媒体查询软件：模块导航、图文浏览与视频控制。
- 互动飞屏软件：拖动素材、视觉反馈与双端播放联动。
- 绿幕拍照系统：背景选择、拍照录像、签名合成、照片墙与扫码下载。
- 签字留念系统：平板拍摄、选片签字与分屏照片墙。

每个项目包含介绍、技术标签、核心功能、操作流程与三张界面截图。内容整理自项目操作说明与技术资料，截图为说明书原图，开发测试画面在图注中标明。

## 本地查看与维护

直接打开 `index.html` 即可查看。下载打包版本时，入口位于 `dist/index.html`。

- `index.html`：首页、作品卡片与工作室介绍。
- `content.js`：项目详情、功能、流程与截图说明。
- `styles.css`：电脑与手机排版。
- `app.js`：详情弹窗、图片原图链接和键盘交互。
- `*-cover.png` / `*-detail-*.png`：项目界面截图。

修改作品名称、简介或封面时，同时更新 `index.html` 中的首页卡片和 `content.js` 中的详情资料。图片使用相对路径；保留项目的 `id` 与卡片的 `data-open` 一致。

## 发布

网站使用 GitHub Pages。发布来源为 `main` 分支根目录。更新时，将本地 `dist/` 文件夹中的文件上传至仓库根目录，提交后等待 Pages 部署完成。

网站无需构建、数据库、付费字体或第三方脚本。
